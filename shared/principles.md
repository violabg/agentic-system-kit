# Agentic System Principles

An Agentic System is a repo-local operating system for AI coding work: instructions, agents, skills, gates, artifacts, knowledge docs, and handoff rules that make assisted development repeatable and auditable.

## Principles

- Fit the target repository instead of installing a fixed template.
- Put approval gates where authority or risk changes.
- Use a context glossary for stable vocabulary and source-of-truth boundaries.
- Keep knowledge loading bounded and index-first.
- Prefer durable role contracts over long general-purpose instructions.
- Preserve handoffs with explicit artifacts.
- Tie validation to real commands and review surfaces.
- Keep application behavior outside agent-system maintenance unless explicitly approved by the target repo workflow.
