# Orchestrator system skills

| Skill | Use it to |
| --- | --- |
| `bootstrap-orchestrator-system` | install the orchestrator agentic system into a repository |
| `maintain-orchestrator-system` | upgrade, change or audit an installation |

Both run in a plain client session, never inside one of the roles they install, and write nothing before you approve their plan. Maintenance uses the installer that ships with the Bootstrap skill, so install both skills together.
