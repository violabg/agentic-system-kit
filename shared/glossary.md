# Glossary

## Agentic System

A repo-local operating system for AI coding work: instructions, agents, skills, gates, artifacts, knowledge docs, and handoff rules.

## Bootstrap

The process of designing and installing the first coherent Agentic System for a repository.

## Maintenance

The process of updating an existing Agentic System when repository structure, workflow, knowledge, validation, or risks change.

## Gate

A named checkpoint where the agent must validate scope, gather required evidence, obtain approval, or run verification before proceeding.

## Artifact

A durable file or structured output used to preserve plans, decisions, validation, handoffs, or review findings.
